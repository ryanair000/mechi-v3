Moderator Duties on Match Day
✅ Before Match Starts
  • Confirm check-in window is open with admin
  • Monitor player check-in via the dashboard
  • Answer player questions in designated WhatsApp groups
  • Direct unregistered players to mechi.club to register
  • Flag any player with a pending payment to admin
🎮 During the Match
  • Monitor room and report lobby issues immediately
  • Record kills/scores for battle royale games
  • For eFootball, verify match result screenshots
  • Handle no-shows by marking them on the bracket
  • Do not alter scores — all updates go through admin
🏆 After the Match
  • Collect final leaderboard / bracket results
  • Send results summary to admin immediately
  • Announce winners in the group (admin confirms first)
  • Do not commit to prize timelines — admin handles payouts
  • Archive screenshots for dispute resolution
💬 Player Communications
  • Keep replies factual — no speculation on prizes or results
  • Redirect payment questions to admin immediately
  • Disputes must be escalated — do not rule on them
  • Use official PlayMechi language (no personal promises)
  • Do not share player personal data with anyone
