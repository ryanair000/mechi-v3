# PlayMechi 24 Screens — React + Vite

This is a detailed React/Vite prototype for the 24 PlayMechi app screens.

## Included screens

1. Splash
2. Login
3. Sign Up
4. Home
5. Tournaments
6. Tournament Detail
7. My Matches
8. Blog
9. Blog Detail
10. Edit Profile
11. Onboarding 1
12. Onboarding 2
13. Onboarding 3
14. Onboarding 4
15. Notifications
16. Challenges
17. Challenge Detail
18. Leaderboard
19. Results
20. Match History
21. Payment Methods
22. Help & Support
23. Settings & Security
24. Game Details

## Updates included

- Home screen matches the reference direction closely.
- Bottom navigation uses a floating glass deck.
- Wallet is replaced with Blog.
- Profile is replaced with Challenges in the bottom nav.
- Profile avatar appears beside notifications.
- Uses local optimized assets cropped from the reference plus coded layouts.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Navigation

Use the left preview menu on desktop. In mobile view, screens still work as individual app views via the query string:

`/?screen=home`
`/?screen=tournaments`
`/?screen=blog`
